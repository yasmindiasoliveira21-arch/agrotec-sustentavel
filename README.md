# Agro Forte, Futuro Sustentável: Produção e Meio Ambiente 🌾✨

Este é um site interativo desenvolvido para apresentar como a tecnologia moderna aliada ao agronegócio pode impulsionar a produção de alimentos sem agredir o meio ambiente.

## 🚀 Funcionalidades
- **Painel Dinâmico de Pilares:** Apresenta conceitos de tecnologia, preservação e energia de forma limpa e sob demanda.
- **Simulador Interativo:** Permite simular o impacto ecológico de diferentes abordagens agrícolas no campo.
- **Design Responsivo:** Adaptado para leitura em computadores e dispositivos móveis.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Variáveis nativas e Flexbox)
- JavaScript (Manipulação de DOM)
